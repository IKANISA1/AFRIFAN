# Google Search Console Submission Guide — Gikundiro

Ensures CWV data is tracked in GSC and the site is properly indexed.

---

## 1. Property Verification

### Setup
1. Go to [Google Search Console](https://search.google.com/search-console)
2. **Add property** → Select "URL prefix"
3. Enter: `https://gikundiro.com`

### Verification Methods (choose one)
| Method | Steps |
|:--|:--|
| **DNS TXT record** (recommended) | Add TXT record to `gikundiro.com` via Cloudflare DNS |
| **HTML tag** | Add `<meta name="google-site-verification" content="TOKEN" />` to root layout |
| **HTML file** | Upload `googleXXXX.html` to `public/` |

### Admin subdomain
Repeat for `https://admin.gikundiro.com` if you want separate admin-specific data.

---

## 2. Sitemap Submission

1. In GSC → **Sitemaps** panel
2. Enter: `https://gikundiro.com/sitemap.xml`
3. Click **Submit**
4. Verify status shows "Success" after crawl

**Note:** The sitemap is dynamically generated by `src/app/sitemap.ts` and includes:
- Static routes (`/`, `/app`, `/tickets`, `/Groups`, etc.)
- Dynamic routes (news, products, matches)
- Admin routes are excluded (correct behavior)

---

## 3. Core Web Vitals Monitoring

### Current implementation
- `web-vitals` v5 reports LCP, INP, CLS, FCP, TTFB from real users
- Data is sent via `navigator.sendBeacon` to `NEXT_PUBLIC_VITALS_ENDPOINT`

### GSC integration
1. In GSC → **Core Web Vitals** panel
2. Review "Mobile" and "Desktop" reports
3. Check that pages are classified as "Good" for:
   - LCP ≤ 2.5s
   - INP ≤ 200ms
   - CLS ≤ 0.1

### Action items
- [ ] Set `NEXT_PUBLIC_VITALS_ENDPOINT` to a collection endpoint (e.g., BigQuery, Vercel Analytics, or custom)
- [ ] Verify sufficient traffic for CrUX data (28-day rolling window)
- [ ] Set up GSC email alerts for CWV regressions

---

## 4. robots.txt Verification

Current `robots.ts` correctly:
- Allows `/` for all crawlers
- Disallows `/admin` and `/api/*`
- Points to sitemap at `https://gikundiro.com/sitemap.xml`

Verify in GSC → **Settings** → **robots.txt** that the file is recognized.
