# Kinyarwanda store-copy source

The mobile binary supports Kinyarwanda, but the current official language lists
for Google Play store listings and App Store Connect metadata do not include
Kinyarwanda. The copy in this directory is preserved for product review,
screenshots, help content, and future portal support. It is intentionally outside
both Fastlane upload trees and must not be mislabeled as another language.

Native-language approval remains required before this copy is published on any
supported surface.
