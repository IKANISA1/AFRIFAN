# App Store Connect portal-entry checklist

## Account and app record

- [ ] Organization membership and agreements are active.
- [ ] App record uses bundle ID `rw.ikanisa.rayonSports` and intended legal entity.
- [ ] Apple ID and immutable SKU are captured in the portal-values record.
- [ ] Version/build `1.0.3 (5)` is unused, or build number was incremented.
- [ ] Distribution certificate/profile/capabilities match the final archive.
- [ ] Countries, free/paid status, primary category, and release method are approved.
- [ ] DSA status and any applicable tax/banking agreements are complete.

## Metadata and compliance

- [ ] English, French, and Kinyarwanda metadata approvals recorded.
- [ ] iPhone and iPad screenshot sets pass the artwork manifest.
- [ ] App icon is present in the exact archive.
- [ ] Privacy/support/marketing URLs verified live.
- [ ] App Privacy answers match exact archive and SDK privacy report.
- [ ] Age-rating questionnaire and regional results approved.
- [ ] Content-rights authority recorded.
- [ ] Export-compliance answer approved.
- [ ] Payments, memberships, rewards/contests, and UGC classifications closed.
- [ ] Accessibility Nutrition Labels contain only physically verified claims.

## Review and artifact

- [ ] App Review contact and non-expiring demo access entered only in the portal.
- [ ] Review notes list exact enabled features and payment/reward boundaries.
- [ ] Exact-commit signed IPA/archive hash and signing evidence recorded.
- [ ] Xcode validation and privacy report complete.
- [ ] Upload processed without unresolved binary, privacy, entitlement, or export warnings.
- [ ] Store-installed TestFlight UAT on iPhone and iPad complete.
- [ ] Build attached to version; submission created; **Submit for Review** explicitly completed.
- [ ] Submission status and timestamp captured from App Store Connect.
